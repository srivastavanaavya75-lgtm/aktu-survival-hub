# 🚀 AKTU Survival Hub

A modern, student-friendly academic dashboard built to help AKTU students access **subjects, syllabus, PYQs, notes, and resources** in one place.

---

## 🌐 Live Demo
👉 https://your-username.github.io/aktu-survival-hub/

---

## ✨ Features

- 📚 8 Semester complete BTech structure
- 🔍 Smart subject search system
- 🧭 Clean dashboard UI
- 🧊 Glassmorphism modern design
- 📱 Responsive layout
- 📦 JSON-based dynamic data system
- ⚡ Fast and lightweight (no backend dependency)

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Glassmorphism UI)
- JavaScript (Vanilla)
- JSON (for data handling)
- GitHub Pages (Hosting)

## 💡 Key Idea

This project was built to solve a real student problem:
> “All AKTU study material scattered in different places.”

Now everything is centralized in a single dashboard.
